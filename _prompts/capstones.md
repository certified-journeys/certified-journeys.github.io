# Certified Journeys — Capstone Registry

One entry per course. When building a new course, check this list before setting
`CAPSTONE_PROJECT` in the course input. Add your new entry here after the course ships.

No two courses may share the same capstone artifact.

| Course ID         | Capstone artifact |
|-------------------|-------------------|
| duckdb-certified  | Analytical lakehouse pipeline querying remote Parquet files over HTTPS |
| fastapi-certified | Bookmarks REST API with JWT auth, pagination, and full OpenAPI docs |
| pandera-certified | Production pipeline validation suite with full test coverage |
| sodacore-certified | Data quality framework for a multi-table pipeline |
| kestra-certified  | End-to-end orchestrated data pipeline in Kestra |
| pydantic-certified | Type-safe config and schema layer for an ML pipeline |
| ray-certified     | Distributed ML pipeline: Data → Train → Tune → Serve |
| prefect-certified | Production ETL pipeline with scheduling, retries, and notifications |
| mlflow-certified  | Full MLOps pipeline: Train → Track → Register → Serve |
